# GRAVEDIGGER v0.1 — сборка и установка

Плагин-инструмент (VST3) для FL Studio. Играешь мелодию, плагин состаривает её как старую пластинку, записывает и сам режет на 16 кусков («костей») на клавишах C5–D#6.

## Способ 1. Сборка через GitHub (без установки программ, ~15 минут)

1. Зарегистрируйся на github.com (бесплатно).
2. Нажми **New repository** → любое имя, например `gravedigger` → можно **Private** → **Create repository**.
3. На странице репозитория нажми **uploading an existing file** и перетащи туда **всё содержимое** распакованной папки `Gravedigger` (включая папку `.github`, `Source`, `CMakeLists.txt`). Нажми **Commit changes**.
   - Если папка `.github` не загрузилась (Windows иногда её не перетаскивает): **Add file → Create new file**, в имени напиши `.github/workflows/build.yml` и вставь текст из этого файла.
4. Открой вкладку **Actions**. Сборка запустится сама (жёлтый кружок). Ждать 10–20 минут, пока не станет зелёной галочкой.
5. Нажми на завершённую сборку → внизу **Artifacts** → скачай **Gravedigger-Windows-VST3** (для Mac — `Gravedigger-macOS-VST3-AU`).
6. Распакуй и скопируй папку **Gravedigger.vst3** в
   `C:\Program Files\Common Files\VST3\`
7. FL Studio → **Options → Manage plugins → Find installed plugins**. Gravedigger появится в списке инструментов: добавь его в Channel Rack.

Если сборка стала красной: открой её, нажми на красный шаг, скопируй последние строки ошибки и пришли мне. Исправлю.

## Способ 2. Сборка у себя на Windows

Нужны: Visual Studio 2022 Community (галочка «Desktop development with C++»), Git и CMake.
```
cd Gravedigger
cmake -S . -B build
cmake --build build --config Release --target Gravedigger_VST3
```
Готовый плагин будет в `build\Gravedigger_artefacts\Release\VST3\Gravedigger.vst3`.

## Mac

Плагин без подписи Apple. После копирования в `~/Library/Audio/Plug-Ins/VST3/` выполни в Терминале:
`xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Gravedigger.vst3`

## Как пользоваться

1. **I · THE BODY**: выбери инструмент (пианино, rhodes, гитара, струнные, хор) и играй мелодию в piano roll FL.
2. **II · THE GRAVE**: крути **YEARS BURIED**, это одна ручка, которая старит всё сразу. Остальные ручки для тонкой настройки:
   - ROT — треск винила;
   - DROWN — плавание плёнки;
   - SINK — опускает питч, как замедленная пластинка;
   - MOLD — убирает верха;
   - GHOST — хвост старой комнаты;
   - BLEED — тёплая сатурация.
   
   **TOMB** выбирает стиль старения.
3. Нажми красную **CAPTURE** и выбери 4, 8 или 16 тактов. Если FL играет, запись начнётся с ближайшего такта. Если стоит на паузе, то с первой ноты.
4. **III · THE BONES**: после записи плагин сам переходит в режим BONES, и сэмпл нарезан на 16 кусков на нотах **C5–D#6**.
   - **HITS** режет по ударам, **EVEN** режет на равные куски, **RE-DIG** предлагает другой вариант нарезки.
   - Клик по пэду: прослушать кусок. **Перетащи пэд мышкой в FL** (в Playlist или на канал), и кусок станет WAV-файлом.
   - **DRAG TO FL** перетаскивает весь сэмпл целиком.
   - Записанный сэмпл сохраняется вместе с проектом FL.

Глаз в центре моргает в ритм трека, следит за нотами и кусками и расширяет зрачок на громких местах.
